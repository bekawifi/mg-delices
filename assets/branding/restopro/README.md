# Identité visuelle RestoPRO

Ce dossier centralise les futurs éléments officiels de la marque logicielle RestoPRO.

- `logo-placeholder.svg`, `logo-square-placeholder.svg` et `icon-source-placeholder.svg` sont des repères techniques temporaires, pas le logo final.
- Remplacer ce fichier après validation de la charte, puis décliner les icônes Tauri dans `src-tauri/icons/`.
- Les logos des restaurants restent configurables par établissement via `restaurant_settings.logo_url` et ne doivent pas être placés ici.
